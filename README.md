# 엘레멘트티엘 Gen2 홈페이지 시안 (HTML)

Figma 최종 시안(메인 C-2 + 하위 7개 페이지)을 반응형 정적 HTML로 옮긴 검토용 시안입니다.
빌드 과정 없이 브라우저로 바로 열 수 있습니다. (Figma 기준 동기화: 2026-11-04)

## 보는 방법

- **`preview.html`** — 검토용 화면. 상단에서 페이지와 PC / Tablet / Mobile 폭을 골라 한 화면에서 확인합니다.
- `index.html` — 실제 홈페이지처럼 메인부터 메뉴를 따라 이동하며 확인합니다.

## 페이지

| 메뉴 | 파일 |
|---|---|
| 메인 | `index.html` |
| 제품소개 › 엘레멘트티엘 Gen2 | `product.html` |
| 공지사항 › 보도자료 · 학회 & 전시 · 블로그 | `press.html` · `conference.html` · `blog.html` |
| 고객지원 › 제품 도입 문의 · 데모 신청 | `inquiry.html` · `demo.html` |
| 병원찾기 › 도입 병원 찾기 | `clinics.html` |

반응형 기준: PC 1440 / Tablet ≤1024 / Mobile ≤640 (390 기준 검수)

## 구조

- `assets/css/style.css` — 디자인 토큰(Figma `ETL-C/Color`와 동일), 공통 컴포넌트, 페이지 스타일
- `assets/js/main.js` — 공통 헤더(메가메뉴·모바일 메뉴·언어 선택)·푸터·플로팅 문의 버튼, 레이저 라인 그래픽, 파장 탭, 뉴스 캐러셀, 임상 사례 필터·캐러셀
- `assets/img/` — 이미지 (로고: `logo-white.png` 어두운 배경용, `logo-navy.png` 밝은 배경용)
- 폰트: Pretendard, Manrope (둘 다 SIL OFL 1.1, 상업적 무료)

## 시안 단계라 아직 연결되지 않은 것

- 문의·데모 폼 전송, 지도 API, 카탈로그 PDF, 언어 전환
- `[ ]`로 표시된 항목: 대리점 사업자정보·연락처, 카카오톡 채널, 의료기기 허가번호, 광고심의필 번호, 학회·전시 일정, 도입 병원 정보
- 「임시 이미지」로 표시된 사진은 최종 촬영본으로 교체 예정
- 임상 사진(제조사 카탈로그 수록)은 웹 게시 사용 동의 확인 전 — 모든 페이지에 `noindex` 적용
- 적용 분야 · 질환명 표기는 식약처 허가사항 및 의료기기 광고 심의 결과에 따라 확정
